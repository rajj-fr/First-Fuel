FIRST FUEL — production-style storefront front end
==================================================

Open index.html with a local server (recommended) or deploy the folder to GitHub Pages/Netlify/Vercel.

Included:
- 285-frame scroll animation
- FIRST FUEL branding
- 4 flavors, 250 ML, ₹189
- Add-to-cart + localStorage
- Quick view
- Cart drawer
- FAQ
- Support/help center
- Privacy/Terms/Shipping/Refund/Cookie placeholders
- Responsive design

IMPORTANT:
This is a front-end storefront. The checkout is intentionally a demo. For real orders, connect:
1) a backend/API
2) an order database
3) a payment gateway
4) server-side validation/authentication
5) secure webhook handling
6) HTTPS + production security headers
7) actual reviewed legal policies
8) verified product/ingredient/nutrition information
